# Aimanong LOGO 提示词集

## 设计立意（意境）

**「码农」二字的意境**：低头、谦卑、在代码的田里一寸一寸耕作，带着自嘲的温热。
**AI 带来的转折**：让这个农夫第一次抬起头——**代码开始自己生长**。

所以 LOGO 的三个符号层：

| 符号 | 代表 | 含义 |
|---|---|---|
| **斗笠** | 农 | 码农的自画像，谦卑而亲切 |
| **电路走线** | 码 | 斗笠的竹编纹理 = 电路板走线 |
| **破土新芽** | AI | 从斗笠顶端长出，代码自己生长 |

一句话：**一个让代码自己长出来的农夫。**

## 方案 A（主推）：斗笠 · 电路 · 新芽

AI 生成文字几乎必崩。字体标建议在 Figma 手排：

- 字形：`Aimanong` 用几何无衬线（如 Inter / Poppins / 思源黑体），字重 SemiBold

## 配色规范

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 · 新芽绿 | `#3FBF6F` | 生长、农业、Vue 系的亲近感 |
| 辅色 · 墨绿黑 | `#101B16` | 终端、代码、沉稳 |
| 点缀 · 暖铜 | `#C98A4B` | 电路焊点、泥土、收获（**仅点缀，不超过 10%**） |
| 背景 | `#FFFFFF` | 纯白 |

可选：若想呼应 Laravel，可用 Laravel 红 `#FF2D20` 替换暖铜作点缀，但**主色仍保持新芽绿**，避免与 Laravel 官方视觉混淆。

## 落地建议

1. **模型选择**：
   - 首选 **Recraft v3**（专做矢量 LOGO，可直接出 SVG）
   - 次选 **Flux.1 [pro/dev]** 或 **Midjourney v7**（加 `--style raw --sref` 保持简洁）
   - 不建议用 DALL·E 3（对极简构图和留白控制偏弱）

2. **先出图形，后加文字**：所有提示词都带 `no text`，先拿到干净的图形标，再用 Figma / Illustrator 排字。**不要指望 AI 一次生成带正确文字的 LOGO。**

3. **矢量化**：AI 出的是位图。用 Recraft 直出 SVG，或用 **Vectorizer.ai** / Illustrator 图像描摹转成真矢量，否则放大必糊。

4. **验收三关**（LOGO 是否合格的硬标准）：
   - 缩到 **16×16** 还认得出 → favicon 关
   - 转成**纯单色**还成立 → 印章/刺绣/深色模式关
   - 去掉颜色只留剪影还能辨识 → 形状关

5. **开源项目配套**：定稿后顺手生成 GitHub 社交预览图（1280×640）、README 头图、favicon 全套（16/32/64/180），放在仓库 `docs/assets/` 下。
