# 用 AI 开发你的后台：完整工作流

> **一句话定位**（见[项目宪法](https://github.com/zyzyzzy/aimanong/blob/main/CONSTITUTION.md)）：
> **你是程序员，AI 写代码。**
> 你负责说清楚要什么、判断结果对不对、决定往哪走；
> 「怎么写」交给 AI，由框架保证它不跑偏。
>
> 这不是低代码平台，也不是拖拽建站 ——
> 而是一个**被驯服好的、给 AI 用的后台框架**。

---

## 先说清楚：你的角色

| 你做 | 你不做 |
|---|---|
| ✅ 想清楚要管理什么、有哪些信息 | ❌ 亲自写 PHP 业务代码 |
| ✅ 把需求讲给 AI | ❌ 读 Laravel 源码才能配置 |
| ✅ 在浏览器里验收，提修改意见 | ❌ 手写前端页面（Schema 自动渲染） |

**你仍然需要编程基础**——因为你要能：
1. 把框架装起来（命令行 + Composer + PHP 环境）
2. 判断 AI 给的东西对不对（AI 不是不会错）
3. 在 AI 卡住时提供有效信息（比如把报错贴给它）

> 详见宪法第四章：**使用者是有编程基础的程序员**，
> 熟悉命令行但不必了解框架内部实现。

## 三个词，认识它们就够了

不需要背，用到时回来看。

### 数据表 —— "你要管理的东西"

一类东西 = 一张表。客户表、商品表、订单表、员工表。

### 字段 —— "这个东西有哪些信息"

就是表的列。比如「客户」这张表：

```
客户名称    文字
联系电话    文字
等级        A级 / B级 / C级  ← 三选一
是否已签约   是 / 否
签约日期    日期
备注        长文字
```

> 💡 描述字段时用**业务语言**就行，不用管"字符串""整型"——
> 说「等级是 A/B/C 三选一」，AI 就知道该做成下拉框。

### 后台页面 —— "自动生成的操作界面"

有了表和字段，**列表页和表单就自动有了**，无需你写。

## 完整流程

### 第一步：装框架（照抄即可）

```bash
# 1. 创建 Laravel 12 项目（已有可跳过）
composer create-project laravel/laravel:^12.0 my-admin
cd my-admin

# 2. 安装框架
composer require aimanong/framework

# 3. 安装引导（会自动建号 + 同步权限节点）
php artisan aimanong:install
```

安装命令会问你账号密码。**密码直接回车**会生成 16 位随机强密码并打印——请记下来。

> 装完如果还进不去，见下方「常见问题」。

### 第二步：把服务跑起来

```bash
php artisan serve
```

打开 `http://127.0.0.1:8000/admin`，用刚才的账号登录。
此时是**空的**——因为还没告诉它要管什么。

### 第三步：把需求讲给 AI（**关键**）

打开你的 AI 助手（Claude / ChatGPT / Cursor 任选），
**把下面这段复制过去，替换成你的需求**：

```
我在用 Aimanong 框架开发后台系统。项目目录是：
/完整路径/my-admin

请先读项目根目录的 llms.txt 了解这个框架。

我需要一个「客户管理」功能，需求如下：

【要管理什么】
客户

【每个客户要记录什么信息】
- 客户名称（必填）
- 联系电话
- 客户等级：A级、B级、C级 三选一，默认 B级
- 所属行业：制造业、互联网、金融、教育、医疗、零售
- 客户状态：潜在、跟进中、已签约、已流失
- 负责人
- 客户 LOGO（要能上传图片）
- 签约日期
- 备注（可以写很多字）

【使用上的要求】
- 列表里能按客户名称和负责人搜索
- 列表里能按签约日期排序
- 要能导出给财务
- 等级要能一眼看出来（A级和B级颜色不一样）

【谁能用】
暂时只有我一个人用，权限以后再说

请帮我实现，做完后自己跑一遍框架的校验命令确认没问题。
```

然后等 AI 干活。它会：

1. 读 `llms.txt` 了解框架能力（**不用读源码**）
2. 生成数据表结构
3. 声明式写出 Resource
4. 自己跑 `ai:verify` 校验

> 💡 如果 AI 说不了解这个框架，让它**先读 `llms.txt`**。

### 第四步：刷新浏览器看结果

刷新页面，左侧菜单会出现「客户」，点进去就能新增、搜索、导出。

**到这里你的系统就能用了。**

### 第五步：提修改意见（循环迭代）

不满意就继续用大白话告诉 AI：

| 你可以直接说 | AI 会做什么 |
|---|---|
| "等级那里，A 级要红色，C 级要灰色" | 改配色 |
| "再加一个字段：年营业额" | 加字段 |
| "客户太多了，一页显示 50 条" | 改分页 |
| "这个字段我不需要了，删掉" | 删字段 |
| "列表里要能按等级筛选" | 加筛选 |

每次改完**刷新浏览器**就能看到。

## 验收：怎么判断 AI 做对了

宪法要求「语法通过 ≠ 需求达标」。AI 交付后，你至少核对：

- [ ] 界面上**点得出来**（不是「schema 里有」）
- [ ] 每个字段都对得上你提的需求
- [ ] 必填项真的必填
- [ ] 导出内容跟界面看到的一致
- [ ] 让 AI 跑过 `php artisan ai:verify`

## 常见问题

### 装完进不去后台？

`aimanong:install` **会**创建管理员账号。若仍进不去：

```bash
php artisan aimanong:install --force --admin-user=admin --admin-password='你的密码' --no-interaction
```

### 忘了管理员密码？

```bash
php artisan tinker
```

```php
$u = Aimanong\Models\Administrator::where('username', 'admin')->first();
$u->password = '新密码';
$u->save();
exit;
```

### 登录后左侧菜单是空的？

账号没绑定超级管理员角色：

```bash
php artisan aimanong:permission super admin
```

然后刷新。

### AI 生成的字段不对 / 报错了？

**把完整的报错信息复制给 AI**，不要自己改。

这个框架的错误信息是专门设计过的——
它会告诉 AI「错在哪、可用选项有哪些、正确写法是什么」，
AI 通常一次就能改对。

### 怎么让服务停下来？

回到跑 `php artisan serve` 的终端，按 **Ctrl + C**。

### 关掉终端后网站就打不开了？

是的，`php artisan serve` 是临时服务器。
要一直运行请部署到真实服务器，见[生产部署](./deploy)。

### 改坏了想退回之前的样子？

如果你用 Git：

```bash
git checkout .
```

不会的话，**改之前先复制一份项目文件夹**作备份。

### 数据存在哪？会丢吗？

默认在项目目录的 SQLite 文件里。
**建议定期备份整个项目文件夹**，尤其是 `database` 子目录。
