# 不懂编程，怎么用它给自己造一个后台

> 这一页**不需要任何编程基础**。
>
> 如果你会写 PHP，请直接看 [快速开始](./quickstart) —— 那才是给你准备的。

---

## 先说清楚：你不需要学会编程

这个项目叫 **AI 码农**，顾名思义：**写代码的活儿交给 AI，你负责说清楚要什么。**

所以你的工作只有三件：

| 你要做的 | 你不用做的 |
|---|---|
| 想清楚自己需要管理什么 | ❌ 学 PHP |
| 用大白话把需求讲给 AI 听 | ❌ 写代码 |
| 在浏览器里点点看，说哪里不对 | ❌ 懂数据库 |

**这不是"低代码平台"，也不是"拖拽建站"。**
它是一个"**AI 帮你写代码**"的框架 —— 好处是 AI 写出来的东西
是**标准代码**，将来想找人接手、想加功能、想搬服务器，都不受限制。

---

## 你最终会得到一个什么样的系统

举个例子。假设你开了一家小公司，想管客户，那你会得到一个这样的后台：

**客户列表**——所有客户一目了然：

| 客户名称 | 等级 | 行业 | 状态 | 负责人 | 电话 |
|---|---|---|---|---|---|
| 深圳宏远精密 | 🔴 A级（重点） | 制造业 | 跟进中 | 张伟 | 0755-8899… |
| 杭州云图数据 | 🟠 B级（常规） | 互联网 | 潜在 | 李娜 | 0571-6677… |
| 北京华信医疗 | 🔴 A级（重点） | 医疗 | 已签约 | 王强 | 010-5566… |

**能做的事**（全部自动具备，不用额外开发）：

- ➕ 新增客户、✏️ 修改、🗑️ 删除
- 🔍 按客户名 / 负责人搜索
- ↕️ 点表头排序（按等级、按时间…）
- 📄 分页（数据多了自动分页）
- 📊 一键导出 Excel / CSV 给财务
- 👥 谁能看、谁能改（权限）
- 📋 谁在什么时候改了什么（操作日志）
- 📎 上传客户 LOGO、合同扫描件

**这些都不需要为每个功能单独开发。** 你描述清楚"客户有哪些信息"，
剩下的框架自动生成。

## 三个词，认识它们就够了

不需要背，用到时回来看。

### 词 1：数据表 —— "你要管理的东西"

就像 Excel 的一张 Sheet。**一类东西 = 一张表。**

| 你想管什么 | 就是一张什么表 |
|---|---|
| 客户 | 客户表 |
| 你卖的货 | 商品表 |
| 收到的订单 | 订单表 |
| 员工 | 员工表 |

### 词 2：字段 —— "这个东西有哪些信息"

就是 Excel 的**列**。比如"客户"这张表，字段可能是：

```
客户名称    文字
联系电话    文字
等级        A级 / B级 / C级  ← 三选一
是否已签约   是 / 否
签约日期    日期
官网地址    网址
备注        长文字
```

> 💡 描述字段时，**用你自己的话说就行**。
> 不用管什么"字符串""整型"——那是 AI 要操心的事。
> 你只要说"等级是 A/B/C 三选一"，AI 就知道该做成下拉框。

### 词 3：后台页面 —— "自动生成的操作界面"

有了表和字段，界面就**自动有了**：一个列表页，加一个新增/编辑的表单。

```
你负责：  想清楚有哪些表、每个表有哪些字段
框架负责：列表页、表单、搜索、排序、导出、权限、日志…
```

## 完整流程：从零到一个能用的系统

### 准备阶段（只做一次，约 15 分钟）

你需要一台电脑，装好下面两样东西。**这一步可以找懂技术的朋友帮忙做一次**，
之后就不用再碰了。

| 需要装什么 | 是什么 | 怎么装 |
|---|---|---|
| **PHP 8.2 以上** | 运行后台程序的引擎 | php.net/downloads |
| **Composer** | PHP 的"应用商店" | getcomposer.org |

> 装好后打开终端（Windows 叫"命令提示符"），输入 `php -v`，
> 能看到版本号就说明成功了。

### 第一步：装框架（照抄即可）

在终端里**一行一行**执行下面三条命令。
第一次装会下载一些东西，耐心等 1~3 分钟。

```bash
# 1. 创建一个新项目（my-admin 是项目名，可以改成你喜欢的）
composer create-project laravel/laravel:^12.0 my-admin

# 2. 进入这个项目
cd my-admin

# 3. 安装 AI 码农框架
composer require aimanong/framework
```

然后运行安装程序：

```bash
php artisan aimanong:install
```

**它会问你两个问题：**

```
── 创建第一个管理员账号 ──
 账号 [admin]:              ← 直接回车就用 admin
 密码（直接回车则使用随机强密码）:   ← 直接回车，它给你生成一个强密码
```

> ⚠️ **密码只显示这一次，请立刻记下来。**
> 忘了也没关系，见下方「常见问题」。

最后它会显示：

```
✅ 安装完成

  访问地址: /admin
  登录账号: admin
  登录密码: 你的密码

  ⚠️ 请立即登录并修改密码
```

### 第二步：把服务跑起来

```bash
php artisan serve
```

终端会显示 `Server running on [http://127.0.0.1:8000]`。
**保持这个终端窗口开着**（关掉服务就停了）。

### 第三步：登录看看

浏览器打开 **http://127.0.0.1:8000/admin**

用刚才记下的账号密码登录。你会看到一个空荡荡的后台——
**这是正常的**，因为还没告诉它要管什么。

### 第四步：把需求讲给 AI（关键步骤）

现在打开你的 AI 助手（Claude / ChatGPT / Cursor 任选）。**把下面这段话复制过去**，
把最后的需求部分换成你自己的：

```
我在用 Aimanong 框架开发后台系统。项目目录是：
/完整路径/my-admin

请先读项目根目录的 llms.txt 了解这个框架。

我需要一个「客户管理」功能，需求如下：

【要管理什么】
客户

【每个客户要记录什么信息】
- 客户名称（必填）
- 联系电话
- 客户等级：A级、B级、C级 三选一，默认 B级
- 所属行业：制造业、互联网、金融、教育、医疗、零售 选一个
- 客户状态：潜在、跟进中、已签约、已流失
- 负责人
- 客户 LOGO（要能上传图片）
- 签约日期
- 备注（可以写很多字）

【使用上的要求】
- 列表里能按客户名称和负责人搜索
- 列表里能按签约日期排序
- 要能导出给财务
- 等级要能一眼看出来（A级和B级颜色不一样）

【谁能用】
暂时只有我一个人用，权限以后再说

请帮我实现，做完后自己跑一遍框架的校验命令确认没问题。
```

然后等 AI 干活。它会：

1. 读出框架的全部能力（有哪些字段类型、哪些内置功能）
2. 生成数据表结构
3. 生成页面配置
4. 自己跑校验，确认没写错

> 💡 **如果 AI 说"我不了解这个框架"**，你就说
> "请先读项目根目录的 llms.txt"。那份文件就是专门写给 AI 看的。

### 第五步：刷新浏览器看结果

回到浏览器，**刷新页面**。左侧菜单会多出「客户」，
点进去就能新增、搜索、导出了。

**到这里，你的系统就能用了。**

### 第六步：提修改意见

不满意的地方，继续用大白话告诉 AI：

| 你可以直接说 | AI 会做什么 |
|---|---|
| "等级那里，A 级要红色，C 级要灰色" | 改配色 |
| "再加一个字段：年营业额" | 加字段 |
| "客户太多了，一页显示 50 条" | 改分页 |
| "这个字段我不需要了，删掉" | 删字段 |
| "列表里要能按等级筛选" | 加筛选 |

每次改完，**刷新浏览器**就能看到。

## 常见问题

### 忘了管理员密码怎么办？

在终端里执行（把 `你的新密码` 换掉）：

```bash
php artisan tinker
```

进入后粘贴这段，回车：

```php
$u = Aimanong\Models\Administrator::where('username', 'admin')->first();
$u->password = '你的新密码';
$u->save();
exit;
```

然后用新密码登录。

### 登录后左侧菜单是空的？

说明账号没绑定"超级管理员"角色。执行：

```bash
php artisan aimanong:permission super admin
```

然后刷新页面。

### AI 生成的字段不对 / 报错了怎么办？

**把完整的报错信息复制给 AI**，不要自己改。

这个框架的错误信息是专门设计过的——它会告诉 AI「错在哪、
可用的选项有哪些、正确写法是什么」，AI 通常一次就能改对。

### 怎么让服务停下来？

回到跑 `php artisan serve` 的那个终端窗口，按 **Ctrl + C**。

### 关掉终端后，网站就打不开了？

是的。`php artisan serve` 是个"临时服务器"，只在终端开着时工作。

想让它一直运行（比如给同事用），需要部署到真正的服务器上——
这一步建议找技术人员，或问 AI「怎么把这个项目部署到服务器」。

### 改坏了想退回之前的样子？

如果你会用 Git：

```bash
git checkout .
```

不会的话，**改之前先复制一份整个项目文件夹**作为备份，
出问题就把备份复制回来。

### 数据存在哪里？会不会丢？

数据存在项目目录下的数据库文件里（默认 SQLite）。
**建议定期备份整个项目文件夹**，尤其是 `database` 子目录。

### 真的不需要学编程吗？

**用起来不需要。** 但有两件事会大幅提升体验：

1. **看 AI 生成的东西**——不需要看懂代码，但可以点开文件扫一眼有没有明显不对
2. **会用终端跑命令**——上面用到的 `composer` / `php artisan`
   总共就几个，抄几次就熟了

## 这套方案适合什么、不适合什么

### ✅ 适合

- 内部管理工具（客户、订单、库存、设备、员工…）
- 需要一个"能录入、能查、能导出"的后台
- 想快速验证一个业务想法

### ⚠️ 需要额外考虑

| 情况 | 说明 |
|---|---|
| 要给**大量外部用户**用 | 需要部署、性能优化、安全加固 |
| 涉及**支付/资金** | 必须找专业人士审查 |
| 要对接**第三方系统** | 可以做，但需要 AI 多花几轮 |
| 需要**复杂报表** | 框架目前的报表能力有限（见下方"还在完善"） |

### ❌ 不适合

- 做网站前台（这套只做后台管理）
- 做 App
- 做需要复杂图表/大屏可视化的场景

## 目前还做得不够好的地方

我把短板如实列出来，免得你踩坑：

| 问题 | 影响 | 现在怎么办 |
|---|---|---|
| **表格筛选框没做界面** | 想按状态筛选，界面上找不到入口 | 用搜索框代替，或让 AI 加 |
| **导出只有 CSV，没有 Excel** | Excel 打开 CSV 会有编码提示 | 让 AI 转一下，或用 WPS |
| **报表/统计能力弱** | 「按行业统计客户数」这类做不了 | 导出后用 Excel 做透视表 |
| **没有定时提醒** | 「合同到期前 30 天提醒」做不了 | 需要额外开发 |
| **建表要写代码** | 你自己加不了表，得让 AI 做 | 直接告诉 AI |

> 这些都在待办清单里，会逐步补上。

## 术语表

看到不懂的词，来这里查。

| 词 | 大白话解释 |
|---|---|
| **Resource** | 一份"说明书"，描述你要管理什么、有哪些字段。框架照着它生成页面 |
| **字段** | 一条记录里的某一项信息，相当于 Excel 的列 |
| **数据表** | 一类数据的集合，相当于 Excel 的一张 Sheet |
| **迁移 / migration** | 建表或改表结构的操作，AI 会帮你写 |
| **后台** | 管理数据的界面（这套东西只做后台，不做对外网站） |
| **Schema** | 框架根据你的说明书自动生成的"结构描述"，AI 靠它理解你的系统 |
| **MCP** | 一种让 AI 直接操作你项目的协议，AI 客户端大多支持 |
| **llms.txt** | 项目里专门写给 AI 看的说明文件，AI 读它就懂这个框架 |
| **终端 / 命令行** | 敲命令的黑窗口（macOS 叫"终端"，Windows 叫"命令提示符"） |
| **CRUD** | 增（Create）删（Delete）改（Update）查（Read），后台的基本功能 |
| **RBAC** | 权限系统：谁能看什么、谁能改什么 |
| **字典** | 一堆可选项的集合，比如"客户等级"的 A/B/C |
