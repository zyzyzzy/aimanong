# AI 码农（Aimanong）开发计划

> **AI-First 后台开发框架** · 基于 Laravel 12 + Vue 3
> 版本：v1.0 · 制定日期：2026-10-09

---

## 〇、一句话目标

**让任何 AI Agent 在 5 分钟内理解框架、30 分钟内产出可运行的后台系统。**

北极星指标：**AI 一次成功率**（定义见 §7）——本项目所有技术决策最终都向这个指标看齐。

---

## 一、技术决策记录（ADR）

先把关键决策定死，避免开发中反复摇摆。

| 编号 | 决策 | 理由 | 被否决的方案 |
|---|---|---|---|
| **ADR-001** | **前后端分离**，后端出 JSON Schema，Vue 3 渲染 | 根治 dcat 的 Blade/JS 混写导致的 XSS；同一 Schema 可同时喂给人和 AI | Blade + Vue 混合（维护地狱） |
| **ADR-002** | AI 通道用官方 **laravel/mcp**，自省 API 独立并行 | MCP 已成事实标准；但不把鸡蛋放一个篮子 | 自研私有协议（生态孤立） |
| **ADR-003** | **禁止方法重载/嵌套闭包** | AI 生成多重载和多级闭包时错误率显著上升 | 追求 API 灵活性（人的偏好，非 AI 的） |
| **ADR-004** | **自研 Schema 编译层**，一份声明编译出所有产物 | 消灭文档与实现漂移（AI 出错的最大来源） | 手写文档（必漂移） |
| **ADR-005** | 保留 **PHP DSL**，不做纯 JSON Schema | 保留可编程性，这是相对 amis/owl-admin 的差异化 | 纯 JSON 配置（复杂页面表达力不足） |
| **ADR-006** | 约束写 `^12.0\|^13.0`，抽象版本适配层 | 提前应对 Laravel 13 | 锁死 12.x |
| **ADR-007** | 时间计算统一走框架封装，**禁止裸调 Carbon `diffIn*`** | Laravel 12 强制 Carbon 3，`diffIn*` 返回负数 float，会静默算错（已实测） | 直接调用（埋雷） |

## 二、仓库结构

采用 monorepo，四个子包独立发版。

```
aimanong/
├── packages/
│   ├── framework/               # Composer: aimanong/framework
│   │   ├── src/
│   │   │   ├── Resource.php                    # 用户继承的基类
│   │   │   ├── Grid.php  Form.php  Show.php  Tree.php
│   │   │   ├── Schema/
│   │   │   │   ├── Compiler.php                # 编译枢纽
│   │   │   │   ├── Ast/                        # 声明 AST 节点
│   │   │   │   └── Emitters/                   # 产物发射器
│   │   │   │       ├── JsonSchemaEmitter.php   # → 前端运行时
│   │   │   │       ├── TypeScriptEmitter.php   # → 前端类型
│   │   │   │       ├── OpenApiEmitter.php      # → REST 文档
│   │   │   │       └── AiPromptEmitter.php     # → AI 提示词/llms.txt
│   │   │   ├── Fields/                         # 表单字段（分期实现）
│   │   │   ├── Displayers/                     # 列展示器
│   │   │   ├── Widgets/
│   │   │   ├── Auth/                           # admin guard + RBAC
│   │   │   ├── Ai/
│   │   │   │   ├── CapabilitiesRegistry.php
│   │   │   │   ├── IntrospectionController.php # /__ai/*
│   │   │   │   ├── Verifier.php
│   │   │   │   └── Exceptions/AiReadableException.php
│   │   │   ├── Mcp/
│   │   │   │   ├── AimanongServer.php
│   │   │   │   └── Tools/                      # scaffold/create/validate...
│   │   │   └── Console/                        # ai:verify / ai:capabilities ...
│   │   ├── config/aimanong.php
│   │   ├── resources/views + migrations
│   │   └── tests/
│   └── ui/                      # npm: @aimanong/ui
│       ├── src/components/{Grid,Form,Show,Tree}
│       ├── src/renderer/SchemaRenderer.vue
│       └── src/types/                          # 由 TS Emitter 生成
├── docs/                        # VitePress 文档站
├── demo/                        # 示例项目（同时是 E2E 测试床）
├── llms.txt  llms-full.txt  AGENTS.md
└── .github/workflows/           # CI + Gitee 镜像同步
```

**发布矩阵**：GitHub（主仓）+ Gitee（国内镜像，push 后自动同步）。

## 四、里程碑与排期

总计 **约 37 周（8.5 个月）**，2 人小组可压缩至 ~26 周。

```
W1──────W4──────W7──────────W14──────────W17───────────W26────────W31─────────W37
├─ M0 地基 ─┤├─M1 Schema─┤├─ M2 核心DSL+Vue ─┤├─M3 AI层─┤├─M4 组件库─┤├─M5─┤├─M6─┤
                                              ▲
                                        关键验证点
```

> **M3 前置说明**：我把 AI 能力层提前到 M2 之后立刻做（原计划放 M4 后）。理由：「AI 能否顺畅使用」是本项目核心假设，必须尽早验证；若假设不成立，越早发现损失越小。

### M0 · 地基（W1–W4）

| 任务 | 产出 | 负责 |
|---|---|---|
| 初始化 monorepo、CI、双仓同步 | 仓库可跑通 CI | 后端 |
| Laravel 12 骨架 + `admin` guard（**实现 `rehashPasswordIfRequired()` / `getAuthPasswordName()`**） | 后台可登录 | 后端 |
| RBAC（角色/权限/菜单）+ 中间件 | 权限生效 | 后端 |
| 统一响应格式 + 错误码体系 | `ApiResponse` | 后端 |
| Vue 3 + TS + Element Plus + Vite 初始化 | 前端空壳可构建 | 前端 |
| 布局（侧边栏/顶栏/面包屑）+ 路由 | 后台框架页 | 前端 |

**DoD**：能登录、能按权限显示菜单、前端能读后端菜单数据渲染导航。

**⚠️ 本阶段必须规避的 Laravel 12 断点**（已实测）：
- 安装脚本用 `ServiceProvider::addProviderToBootstrapFile()`（骨架已无 `config/app.php` providers 数组）
- `filesystems.local.root` 默认变 `storage/app/private`，需显式声明
- `AuthenticationException::redirectTo($request)` 必须传参

### M1 · Schema 编译层（W5–W7）★ 架构枢纽

| 任务 | 产出 |
|---|---|
| 声明 AST 设计（Field/Column/Action 节点） | `Schema/Ast/` |
| `Compiler`：PHP 声明 → AST | 编译管道 |
| `JsonSchemaEmitter` | 前端运行时 Schema |
| `TypeScriptEmitter` | 前端类型定义 |
| `OpenApiEmitter` | REST 文档 |
| `AiPromptEmitter` | AI 提示词 / llms 片段 |
| Golden-file 测试（声明 → 快照比对全部产物） | 测试 |

**DoD**：同一份 Resource 声明，四条产物链路全部输出正确；改一处声明，四份产物同步变化。

> 这一层是整个框架的枢纽，**必须优先做对**。它决定了后续文档永不漂移。

### M2 · 核心 DSL + Vue 端到端（W8–W14）

| 任务 | 产出 |
|---|---|
| `Resource` 基类 + 自动路由注册 | `Resource.php` |
| `Grid`：列、搜索、筛选、排序、分页、批量操作 | Grid + Vue Grid |
| `Form`：字段渲染、校验、提交、错误回显 | Form + Vue Form |
| `Show`：详情字段、关联展示 | Show + Vue Show |
| CRUD API（REST）+ Repository 数据源抽象 | API 层 |
| `SchemaRenderer.vue`：消费 Schema 渲染 | 前端核心 |
| E2E：demo 项目跑通用户管理完整 CRUD | 端到端 |

**DoD**：demo 项目的用户管理模块（列表+搜索+筛选+分页+新增+编辑+删除+详情）全部可用，且**完全由 PHP 声明驱动**，前端零硬编码。

### M3 · AI 能力层（W15–W17）★ 核心卖点，关键验证点

| 任务 | 产出 |
|---|---|
| `CapabilitiesRegistry` + `/__ai/capabilities.json` | 机器可读能力清单 |
| `/__ai/openapi.json`、`/__ai/schema/{resource}`、`/__ai/examples/{pattern}` | 自省 API |
| `AiReadableException`：所有异常带 `didYouMean` + `example` + `docs` | 可自愈错误 |
| 方法名/字段名**编辑距离模糊匹配** | 打错也给正确提示 |
| `php artisan ai:verify` 自检命令 | 生成后自校验 |
| **MCP Server**（基于 laravel/mcp v0.4.2，已实测可装） | `list_resources` / `scaffold_resource` / `create_page` / `validate_declaration` / `run_verify` / `query_data` / `search_docs` |
| MCP Prompts：`new-admin-module`、`debug-error` | 标准流程 |
| `llms.txt` + `llms-full.txt` + `AGENTS.md` | AI 入口 |
| **AI 任务集 v1（20 题）+ 多模型实测** | **成功率基线** |

**DoD**：
1. 一个**从未见过本项目**的 AI Agent，仅靠 `llms.txt` + MCP，能独立完成"生成商品管理模块"并跑通 `ai:verify`
2. AI 任务集基线数据产出（见 §7）

> ⚠️ **这是本项目的生死线。** 若 M3 验收不达标，应暂停后续开发，回头重设计 API，而不是继续堆组件。

### M4 · 字段与组件库（W18–W26）

按使用频次分期，不追求一次对齐 dcat 的 67 个字段。

| 批次 | 字段（Top 20 覆盖约 90% 场景） | 周 |
|---|---|---|
| P1 | Text / Textarea / Select / MultiSelect / Switch / Radio / Checkbox / Date / DateTime / Number | W18–W20 |
| P2 | Upload(Image/File) / Editor(Markdown/富文本) / Tree / Table(子表) / Hidden / Display / Color / Rate | W21–W23 |
| P3 | 列展示器 28 个 → Vue 化 + Widgets（卡片/统计/图表/Tab） | W24–W26 |

每个组件必须同时交付：PHP 声明类 + JSON Schema + Vue 组件 + TS 类型 + 文档片段（自动生成）。

### M5 · 增强（W27–W31）

Tree（无限层级拖拽）、分步表单、字段联动、导入导出、多应用、插件系统、**代码生成器**（从数据库表一键生成 Resource）。

### M6 · 生态与文档（W32–W37）

文档站（VitePress，中英双语，API 参考自动生成为主、教程手写）、交互式 Playground、示例项目扩展、AI 任务集扩充至 50 题、首批官方扩展（省市区/OSS/富文本）、v1.0 发布。

## 六、工程规范

### 6.1 分支与提交

- 分支：`main`（稳定）/ `develop`（集成分支）/ `feat/*` `fix/*` `chore/*`
- 提交：**Conventional Commits**（`feat:` `fix:` `docs:` `refactor:` `test:`），用于自动生成 CHANGELOG
- PR 必须：CI 全绿 + 至少 1 人 review + 更新对应测试

### 6.2 质量门禁（CI 强制）

| 工具 | 标准 |
|---|---|
| PHPStan | **Level 8**（最高级，零 error） |
| Pint | Laravel 风格，零 diff |
| PHPUnit/Pest | 核心链路覆盖率 **≥ 80%** |
| Vitest | Vue 组件覆盖率 ≥ 70% |
| Golden-file | Schema 产物快照比对，任何漂移即失败 |
| ESLint + TS strict | 零 error |

### 6.3 版本与发版

- SemVer；`0.x` 阶段允许破坏性变更，`1.0` 后严格兼容
- 发版前必跑：AI 任务集回归（成功率不得下降）
- 每版输出 CHANGELOG + 升级指南

### 6.4 安全（相对 dcat 的核心卖点）

- 统一输出转义层，所有用户输入经 JSON 序列化 + Vue 文本插值
- 公开 `SECURITY.md` 与响应 SLA（dcat 有 4 条 CVE **零补丁**，这是最直观的差异点）
- 依赖漏洞扫描进 CI；MCP/自省 API 默认仅 local/debug 开启，生产需 token

## 七、北极星指标：AI 一次成功率

### 7.1 任务集设计（v1：20 题）

| 难度 | 数量 | 示例 |
|---|---|---|
| **L1 简单** | 5 | 单表 CRUD、加一个字段、改列标题、加必填校验 |
| **L2 中等** | 10 | 带搜索/筛选/导出、关联模型下拉、自定义验证规则、状态枚举列 |
| **L3 复杂** | 5 | 分步表单、树形结构、自定义批量动作、权限细分到按钮、子表嵌套 |

### 7.2 评分标准

| 结果 | 得分 |
|---|---|
| 一次生成即可运行，`ai:verify` 全绿 | **1.0** |
| 需 1 次修正（Agent 读错误信息后自行改对） | **0.5** |
| 需 ≥2 次修正，或需人工介入 | **0** |

### 7.3 目标基线

| 难度 | v1.0 目标 |
|---|---|
| L1 | **≥ 95%** |
| L2 | **≥ 85%** |
| L3 | **≥ 70%** |

### 7.4 测量方式

- 每轮用 **Claude / GPT / DeepSeek / 通义** 各跑一遍，取均值与最低值
- **只看最低值**：某个模型显著偏低说明 API 对该模型不友好，必须优化提示词或 API 设计
- 每月一次全量回归 + 每次发版增量回归
- 结果公开在文档站（这是最强的营销素材，也是诚实的质量承诺）

## 九、风险台账

| 风险 | 概率 | 影响 | 应对 | 触发信号 |
|---|---|---|---|---|
| **AI 一次成功率不达标** | 中 | **致命** | M3 即验证；不达标就回炉重设计 API，而非继续堆组件 | M3 验收 L2 < 70% |
| 组件数量导致工期膨胀 | 高 | 高 | 严格按 Top 20→P2→P3 分期；预留 `CustomComponent` 逃生舱 | M4 过半未完成 P1 |
| MCP 协议/客户端变动 | 中 | 中 | 跟随官方 laravel/mcp；自省 API 独立于 MCP | 协议 breaking change |
| 前端复杂度超预期 | 中 | 中 | Schema 驱动，前端只做渲染器，复杂度可控 | Vue Grid 超 3 周 |
| Laravel 13 破坏性变更 | 低 | 中 | ADR-006 版本适配层 | L13 发布 |
| 开源无人参与 | 中 | 中 | 文档站 + AI 协作指南 + Good First Issue | 半年 < 3 外部贡献 |
