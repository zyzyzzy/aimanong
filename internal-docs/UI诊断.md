# UI 现状诊断

> 用户反馈：「整个页面效果不好看，甚至可以说非常的丑。」
> 以下是量化体检结果（不是主观感受，是数据）。

## 一、根本问题：没有设计系统

| 症状 | 数据 | 说明 |
|---|---|---|
| **零设计 token** | CSS 变量 **0 个** | 所有值都是硬编码 |
| **色值散乱** | **25 个**不同色值 | `#dde3e0` 出现 15 次、`#3FBF6F` 10 次…没有色板 |
| **CSS 三份重复** | 3 个页面各写一套 | 登录页/首页/列表页互不共享 |
| **间距无网格** | 8/9/12/14/16/24/40px 混用 | 没有 4px 或 8px 基准 |
| **圆角无规范** | 3/4/6/8/10/12px 六种 | 应有 2-3 档 |
| **阴影仅 2 种** | 且是随手写的 | 没有层次体系（卡片/弹窗/悬浮应有不同层级） |

## 二、具体缺陷

### 1. 颜色系统缺失

- 没有**语义色**（success/warning/danger/info 只在零散处硬编码）
- 没有**灰度阶梯**（只有 5-6 个灰，现代设计需要 9-10 级）
- 主色 `#3FBF6F` 偏"廉价绿"（饱和度太高，缺少专业感）
- **没有暗色模式**（`dark` 关键词 0 处）

### 2. 交互反馈贫乏

| 状态 | 覆盖数 |
|---|---|
| `hover` | 7 处 |
| `focus` | 3 处 |
| `transition` | **2 处** |
| `animation` | **0 处** |

→ 页面"死板"，没有现代感所需的微交互。

### 3. 中文字体栈不完整

```
-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif
```

问题：
- 缺 `"Noto Sans SC"`（Linux 环境）
- 缺 `"Source Han Sans"` 系列
- **行高未针对中文加大**（中文需要 1.6-1.75，英文 1.5 即可）

### 4. 图标用 emoji

`📝 🗂 👤 🏷 📦 🧾 🔐 🔑 🏢`

问题：
- **跨平台渲染不一致**（Windows/Mac/Linux 长得完全不一样）
- 无法控制颜色/粗细/大小
- 与"科技感"要求冲突

### 5. 视觉层次单调

- 卡片：白色 + 极浅阴影 + 10px 圆角，**所有卡片长得一样**
- 表格：只有表头底色，无斑马纹、无行 hover、数字未用等宽字体
- 按钮：只有 `btn` 和 `btn-primary` 两种
- 空状态：只有一行灰字「暂无数据」，无插图无引导

## 三、为什么"丑"（根因归纳）

1. **没有 token 层** → 改一个颜色要找 25 处
2. **没有层次体系** → 所有元素视觉权重相同，眼睛没有落点
3. **没有动效** → 缺少"活着"的感觉（现代感很大程度来自过渡动画）
4. **没有暗色模式** → 2025 年的后台没有暗色是不可接受的
5. **emoji 当图标** → 廉价感的最大来源之一
6. **色彩饱和度失当** → 主色太艳，缺乏专业克制感

## 四、改造目标

| 维度 | 现状 | 目标 |
|---|---|---|
| 设计 token | 0 个 | **60+ 个** CSS 变量（色/间距/圆角/阴影/字号/动效） |
| 可选风格 | 无 | **3 套**（可一键切换） |
| 暗色模式 | 无 | **完整支持** |
| 图标 | emoji | **内联 SVG**（可控色/粗细） |
| 动效 | 0 | 过渡 + 微交互（尊重 `prefers-reduced-motion`） |
| CSS 复用 | 3 份重复 | **1 份设计系统**（Blade 组件 / 共享 partial） |
| 中文适配 | 基础 | 字体栈 + 行高 1.7 + 字号阶梯 |

## 五、约束

1. **不引入前端构建步骤**（Vue 目前 CDN 内联）
2. **保持零依赖**倾向（可选：内联自研设计系统）
3. 开源项目：视觉专业但不能抄袭商业产品
4. 无障碍：对比度 ≥ 4.5:1、focus 可见
