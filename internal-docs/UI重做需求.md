# UI 重做需求（用户否决当前设计）

> 用户原话：
> 「这个界面效果，我觉得要全部重新规划重做。
> 1. 整个界面风格像十几年前的风格，太老气了。
> 2. 没有辨识度。有的界面一看就知道是哪个项目的，你现在弄的这个界面没有自己的风格和辨识度。
> 3. 界面布局不能自适应，屏幕大小改变了时，有些布局就挤在一起了。
> 4. 你参考学习一下现在比较热门好看的界面效果，重新再设计一下」

## 一、四点意见的实测印证

### 意见 1：老气 —— ✅ 成立

**骨架是十年前的**：

| 项 | 当前值 | 出处 |
|---|---|---|
| 侧边栏 | 固定 232px | `--w-sidebar: 232px` |
| 顶栏 | 固定 56px | `--h-topbar: 56px` |
| 布局 | `grid-template-columns: 232px minmax(0,1fr)` | design-system.css:320 |

这就是 **Ant Design / AdminLTE 2015 年**的语言：
固定侧栏 + 固定顶栏 + 白色卡片 + 浅灰画布。

### 意见 2：没有辨识度 —— ✅ 成立

**124 个组件类里，18 个是纯布局工具类**（flex/grid/gap/mb/text/items…），
这些完全没有视觉识别度。

真正"自研"的视觉决策接近于零 —— 全是在复刻通用后台模板。

**什么算辨识度**：Linear 的极细边框 + 紧凑排版、Vercel 的黑白极简、
Supabase 的近单色 + 唯一强调色。**我们目前一个都没有。**

### 意见 3：不自适应 —— ✅ 成立（实测数据）

浏览器实测（列表页，12 行数据）：

| 视口宽 | 表格宽 | 容器宽 | 溢出 | 侧栏宽 |
|---|---|---|---|---|
| 1440 | 1158 | 1158 | ✅ | 232 |
| **1280** | 1091 | **998** | ❌ 溢出 | 232 |
| **1024** | 1091 | **910** | ❌ 溢出 | 64 |
| **768** | 1091 | **734** | ❌ 溢出 | **232（反向变宽！）** |

**768px 截图暴露的问题**：
- 侧边栏**完全消失**（应该折叠成图标条，而不是消失）
- 表格文字**被挤成竖排**（"Laravel 12 队列深度实践" → 4 行）
- **操作列被切掉**，看不到编辑/删除按钮

**媒体查询分布**：
```
design-system.css   8 个
themes.css          1 个
user-prefs.css      0 个  ← 密度/圆角覆盖层完全没做响应式
```

### 意见 4：参考热门设计 —— 调研中

## 二、重做的硬约束（不可违反）

| 约束 | 原因 |
|---|---|
| **零构建步骤** | 不能引入 Tailwind 编译 / npm build |
| **零外部 CDN** | 今天刚踩过：jsdelivr 挂了导致后台全废 |
| **三主题 + 亮暗** | 已有 token 体系必须保留 |
| **中文排版优先** | 行高 ≥1.6、字体栈含 Noto Sans SC |
| **对比度 ≥4.5:1** | 已有 72 项校验，不能倒退 |
| **focus 可见** | 无障碍 |

## 三、辨识度的可能来源（待调研确认）

框架叫 **Aimanong（AI 码农）**，LOGO 是：
- 蓝色圆环 + 二进制数字环绕
- 程序员敲代码的人像插画
- "Ai" 橙红 / "m a n" 橙黄 / "nong" 亮绿

**「AI + 码农」是性格内核** —— 设计应该呼应这个，
而不是做成又一个"企业级后台"。

可能的切入点（待验证）：
- **代码美学**：等宽字体、行号、终端感、光标闪烁
- **AI 感**：光晕、渐变、数据流动、呼吸感
- **二进制/圆环**：LOGO 的几何语言

## 四、验收标准

用户验收时应该能回答"是"：
1. 这个界面看着**不老气**吗？
2. 只看截图，**能认出是 Aimanong** 吗？
3. 从 1440 → 1280 → 1024 → 768 → 375 逐档缩，
   **每个宽度都不挤、不切、不重叠**吗？
4. 和我给的参考比，**不逊色**吗？
