两种「干净」的区别
B 的干净是「明亮清爽」—— 白底 + 一处高饱和紫，颜色有存在感但不杂乱； 顶栏那条 4px 四色渐变是全站唯一用满 LOGO 四色的地方，克制才有力。
C 的干净是「极致留白」—— 几乎无彩色，只剩一个绿点；冲击完全靠字号与空间， 没有常驻侧栏，内容单列居中读起来最舒服。

都验证过的：320→2560px 逐 40px 布局扫描零问题；768px 次要列隐藏 + 操作列吸右； 390px 表格卡片化；触控目标 ≥34px；对比度全部 ≥4.5:1。
