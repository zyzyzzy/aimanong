Aimanong · 5 个设计方案

同一份数据、同一批功能，5 种完全不同的设计语言。全部通过 320→1920px 逐像素布局扫描。

#方案基底配色策略布局辨识度来源风险
1终端蓝图Linear + Raycast 暗色 + 唯一强调色常规（侧栏） 等宽数据层、圆环符号、Agent 徽标低 · 最稳妥
2色谱铺开Stripe + PostHog LOGO 四色全用常规 + 全宽渐变头图 渐变头图、彩色统计卡中 · 渐变易"糊"
3亮色精密Vercel + Linear 亮色 近黑白 + 细彩条顶部横导航 52px 超大标题、无卡片设计低 · 最"高级"
4Agent 中心无先例（原创） 暗色 + Agent 状态色Agent 任务队列 界面显示 AI 在做什么高 · 依赖后端接口
5二进制极简Supabase 近单色，仅状态有色常规（窄侧栏） 二进制底纹、无底色状态标签低 · 最克制
01

终端蓝图

Linear + Raycast 调研推荐
气质冷静、精密、开发者工具
配色暗色画布，唯一强调色（LOGO 蓝）
辨识度等宽数据层 + 圆环符号 + Agent 徽标
成本12.6KB gzip · 已有可用 CSS
768px · 抽屉 + 次要列隐藏390px · 表格卡片化
02

色谱铺开

Stripe + PostHog
气质活力、大胆、有冲击力
配色LOGO 四色全用（蓝/橙红/橙黄/绿）
辨识度全宽渐变头图 + 每张统计卡一个色相
成本10.3KB · 纯 CSS
768px390px
03

亮色精密

Vercel + Linear
气质干净、高级、留白充裕
配色近黑白 + 统计卡细彩条
辨识度52px 超大标题、无卡片（极细分隔线）、顶部横导航
成本11.0KB · 纯 CSS
768px390px
04

Agent 中心

原创 · 无先例 唯一抄不走的
气质像在"指挥 AI 干活"，而不是"自己操作后台"
配色暗色 + Agent 状态色驱动
辨识度Agent 任务队列（带进度）+ 行级"正在写入"扫描线 + 顶栏呼吸指示
成本CSS 低，但需要后端 Agent 状态接口
768px390px
05

二进制极简

Supabase
气质克制、冷静、高级灰
配色近乎全无彩色，只有"状态"和"变化中的数字"带色
辨识度二进制底纹、无底色的极简状态标签、主按钮不用色
成本16.1KB · 纯 CSS
768px390px
