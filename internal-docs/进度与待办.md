5. `auto` 上传模式判断依据错误（新项目必得坏图）

## 四、已知问题（不阻塞发版）

1. **本机验证环境无显示器**
   - `screencapture` 报 `could not create image from display`
   - Chrome 中**页面加载后新启动的动画不会推进**，截图会拍到动画中间态
   - 截图前必须注入 `animation:none; transition:none`，详见 [验证方法论](./验证方法论.md)

2. **demo 应用与仓库不在同一目录**
   - 仓库里 `demo/` 是空目录，实际演示项目在 `../demo-app`
   - `scripts/pre-release.sh` 通过 `DEMO_PATH` 环境变量定位

3. **`packages/ui` 尚未实际启用**
   - 前端目前是单文件 Vue（`resources/views/` 内联），零构建
   - `packages/ui` 的 Vue 组件库是规划中的产物，当前没有消费者
