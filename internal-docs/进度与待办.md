## 四、已知问题（不阻塞发版）

1. **demo-app 的 `ai:verify` 有 2 项未通过**（本地测试应用，非仓库内容）
   - `shop-addresses`：`area` / `city_only` 是 region 插件字段，不是数据库列
   - `users`：`status` / `enabled` 声明了但 `users` 表没有这两列
   - 这是 `SUSPECT_FIELD` 检查**正常工作**的结果（demo 声明本身不完整），
     但演示项目带着失败的自检不好看，建议随阶段 2「用户管理增强」一起补齐。

2. **本机验证环境无显示器**
   - `screencapture` 报 `could not create image from display`
   - Chrome 中**页面加载后新启动的动画不会推进**，截图会拍到动画中间态
   - 截图前必须注入 `animation:none; transition:none`，详见 [验证方法论](./验证方法论.md)
